# ImageDeduplication

基于 Qt Widgets/SQLite 的图片相似度检测与清理工具原型，支持多目录扫描、相同/相似图片分组、回收站删除、导出报告与设置持久化。

## 已实现功能

- 多目录扫描与目录列表管理
- 扫描深度、隐藏目录、扩展名、文件大小过滤
- aHash / pHash / dHash 三种感知哈希算法
- MD5 / SHA-256 完全相同识别与感知哈希相似分组
- SQLite 持久化目录、图片、分组与失效记录
- 分组结果树、属性面板、大图预览与扫描日志
- 删除至回收站、CSV/HTML 导出、失效记录清理
- `QSettings` 持久化常用扫描参数

## 构建

```bash
cmake -S . -B build
cmake --build build
```

### 依赖

- Qt 6.x（Core / Gui / Widgets / Sql；目标环境为 Qt 6.8）
- CMake 3.21+
- C++17 编译器

## 运行说明

1. 启动应用后通过“添加目录”加入待扫描目录。
2. 根据需要调整扫描深度、过滤条件、哈希算法与相似度阈值。
3. 点击“开始扫描”生成相似图片分组。
4. 选中图片后可预览、导出、删除到回收站或打开所在目录。
